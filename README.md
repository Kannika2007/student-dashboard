\# Student Performance Prediction \& Analytics Dashboard



A Machine Learning based web application to analyze student performance and predict estimated scores.



\## Technologies Used

\- Python

\- Flask

\- React

\- TypeScript

\- SQLite

\- Scikit-learn

\- Pandas



\## Features

\- Add and manage student records.

\- Enter attendance, internal marks and study hours.

\- Predict estimated student scores.

\- Classify students into Low, Medium and High risk levels.

\- Display analytics using charts.

\- Search and filter student records.

\- Store data using SQLite.

\- Validate user inputs.



\## Project Structure

\- backend - Flask API and Machine Learning

\- frontend - React and TypeScript



\## Important Note

This project is developed for educational purposes. Predictions are estimates based on synthetic training data and are not official academic results.
